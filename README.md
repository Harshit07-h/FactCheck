# Truth Layer - AI Fact Checker

An AI-powered fact-checking web application built using Python and Streamlit.

## Features
- Fact verification
- Web evidence analysis
- PDF support
- AI-powered reasoning
- Report generation

## Tech Stack
- Python
- Streamlit
- APIs
- Pandas

## Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
